Tres direcciones para mnkykonnekt.com

Ábrelas en el móvil y en el portátil, una detrás de otra, y dime cuál. Cada una es el hero y la primera sección, no la web entera.

  • A

    Built in front of you

    Una web de pyme se construye sola en pantalla mientras bajas: entran los precios, el horario, el mapa, el WhatsApp. El movimiento enseña el producto.

  • B

    Before → After theatre

    La web vieja de una peluquería a pantalla completa se transforma en la nueva con un barrido, y luego la mueves tú con el comparador.

  • C

    Studio editorial

    Registro oscuro, tipografía enorme, retícula visible, texto que se ilumina al bajar y una rejilla de trabajos. Lo más «estudio caro».
